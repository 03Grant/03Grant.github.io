# 03Grant.github.io

Source of [Yinghao He's personal homepage](https://03grant.github.io/): a small Jekyll site with no theme,
built by GitHub Pages.

- `_config.yml` — name, email, links, optional photo
- `index.html` — home page (about, research, publications, news)
- `cv.md` — CV page; `files/YinghaoHe_CV.pdf` is the PDF it links to
- `_publications/*.md` — one file per paper (title, authors, venue, date, arXiv and code links)
- `_layouts/default.html`, `_includes/pub.html`, `assets/css/style.css` — layout and style
