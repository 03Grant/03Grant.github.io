I am a second-year PhD student in Computer Science at [Purdue University](https://www.cs.purdue.edu/), where I started in August 2025. Before Purdue, I received my B.Eng. in Software Engineering from Tongji University (2021–2025).

I'm passionate about interesting things! Currently I work on the reliable behavior of large language models, and I also spend a lot of time improving the performance of AI infrastructure, especially storage.

Research interests
======
* **Sycophancy and contextual stubbornness in LLMs.** I built CoPE-Bench, which jointly evaluates how a model responds to user pressure and to contextual evidence, and SPAE, a training-free attention-steering method that suppresses user pressure and amplifies contextual evidence using token spans the model identifies itself.
* **Disk-based vector search.** Retrieval systems that keep compressed representations in memory and use cluster-centroid indexing and estimated-distance filtering to serve datasets larger than memory from commodity storage.
* **Agentic data pipelines.** Agents that turn a natural-language data request into a curated dataset for LLM training, with search tools, a crawler and an evaluation loop.
